# AAC (Augmentative and Alternative Communication)

A lightweight, child-friendly Progressive Web App (PWA) designed to help children with communication challenges express their needs, emotions, and actions using visual symbols.

## 🚀 Live Demo
**[https://dileepyeligari-byte.github.io/Simple-AAC/](https://dileepyeligari-byte.github.io/Simple-AAC/)**

## ✨ Features
- **Progressive Learning Levels**: 4 levels of vocabulary complexity to reduce the learning curve.
  - **Level 1**: Foundation (Needs & Self - ~12 cards)
  - **Level 2**: Building (Actions & Emotions - ~30 cards)
  - **Level 3**: Explorer (Questions & Items - ~60 cards)
  - **Level 4**: Master (Full vocabulary)
- **Bilingual Support**: Toggle between **English** and **Telugu** modes instantly.
- **Parent Gate Security**: Child-proof settings access (Long-press the gear icon for 2 seconds).
- **Customization**:
  - Add or Edit any card (Change Emoji, Text, or Category).
  - **Record Custom Voice**: Record your own voice for each card so the app speaks in a familiar voice.
  - **Custom Photos**: Upload personal photos to replace emojis for people or items.
- **Offline Mode**: Works without an internet connection once installed on a tablet or phone.
- **Privacy First**: All data (custom cards, recordings, photos) is saved locally on the device using IndexedDB. No data is sent to a server.

## 🛠️ Installation
1. Open the [Live Link](https://dileepyeligari-byte.github.io/Simple-AAC/) in Chrome on your tablet or phone.
2. If prompted, tap "Add to Home Screen" or "Install App".
3. If the prompt doesn't appear, tap the three dots (⋮) and select "Install app".
